# AI CRM SaaS

A full-stack AI-powered sales CRM inspired by the product demonstrated in the supplied tutorial transcript. Original implementation; not copied source code.

## Stack
React 19, Vite, Tailwind CSS v4, Node.js, Express, MongoDB/Mongoose, JWT, bcryptjs, Google Gemini, Recharts, Axios and Lucide React.

## Features
- Authentication and owner-scoped data
- Dashboard analytics
- Leads CRUD and AI analysis
- AI email drafting and pipeline insights
- Contacts, notes and follow-up tasks
- Visual five-stage pipeline with persisted order
- Demo seed data

## Local setup
See `backend/.env.example` and `frontend/.env.example`.

Backend: `cd backend && npm install && npm run seed && npm run dev`
Frontend: `cd frontend && npm install && npm run dev`

Demo: `demo@ai-crm.local` / `Test1234` after seeding.
